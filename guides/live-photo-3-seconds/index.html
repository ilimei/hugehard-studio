视频转实况为什么最长 3 秒：怎么从长视频里选片段

作者与维护：HugeHard Studio · 更新于 2026年11月26日 · “相机”拍摄实况照片的时长说明依据 Apple《让照片生动起来》；iOS 界面会随版本变化，以手机上的实际显示为准

在《这图能改》里把视频转成实况照片（Live Photo）时，可选片段最长 3 秒。这和 iPhone 用“相机”拍摄实况照片时、前后各录 1.5 秒的时长相近。原视频更长也没关系，只要从里面选出要动起来的那一段。

先了解这几条边界

《这图能改》的“实况”模式不会把超过 3 秒的片段做成一张实况照片。时间轴会限制可选范围，也会限制最短可选长度。画面不会被加速或压缩进 3 秒，只转换你选中的那一段。

需要保留更长的过程时，请直接分享或发布原视频；或者做成 GIF（片段最长 8 秒，见视频转 GIF 指南）。GIF 不是实况照片，播放和分享方式也不同。

为什么是 3 秒

根据 Apple《让照片生动起来》：拍摄实况照片时，iPhone 会录下拍照前后各 1.5 秒所发生的一切。也就是说，用系统“相机”拍出来的实况照片，动态部分大约就是 3 秒。完整说明见 Apple 支持文档让照片生动起来。

《这图能改》把相册里的视频转成实况照片时，同样把片段限制在最长 3 秒，生成结果可以像普通实况照片一样，在“照片”App 里按住播放。App 不会改系统相机，也不能把一张实况照片的时长做到超过这个上限。完整转换步骤见视频转实况照片教程。

怎么从更长的视频里选出这 3 秒

  1. 打开《这图能改》，在“工作台”选择“照片或视频”，导入相册里的视频；进入编辑器后，在底部模式栏选择“实况”。长边超过 4,096 px 的视频会显示不支持提示。
  2. 先顺着时间轴看完整段视频，想好哪一个瞬间最值得留下来，例如转身、挥手、蜡烛晃动，或一句表情变化最明显的口型。
  3. 在“片段”里标出起点和终点，最长 3 秒；时间轴也会限制最短可选长度。选好后先预览这段原视频，确认开头和结尾都不突兀，再进入下一步。
  4. 在“封面”里选片段内的一帧静帧。封面是别人先看到的那张静止画面，不一定要落在正中间，但应清楚、能代表这段动态。预览和导出使用同一帧。
  5. 再设置“画质”和“声音”。画质档位见视频转实况画质选择；是否保留原片声音见实况照片声音设置。这两项和时长无关，不会让片段变长或变短。
  6. 点击生成，在预览里确认这 3 秒和封面都符合预期，再保存到照片图库。转换在 iPhone 本机完成，不会把视频上传到 App 开发者服务器。
  7. 打开“照片”App，按住这张照片确认会动；也可以在“精选集”→“媒体类型”→“实况照片”里找到它。若按住不动，见实况照片不动排查步骤。

选片段时可以注意什么

  • 优先选画面确实有变化的几秒。几乎静止的片段，做成实况后也很难看出来在动。
  • 尽量让动作在这 3 秒里有比较完整的开头和结尾，避免一开头或结束时动作被切断一半。
  • 准备发到微信或小红书时，动作再明显一些通常更合适，说明见视频做成实况发朋友圈和视频做成小红书实况图。
  • 若打算设成锁屏壁纸，稳定、动作柔和的片段往往更合适；设墙纸是 iOS“设置”里的操作，App 不提供设壁纸功能，兼容性尚未验证。步骤见实况照片设为锁屏壁纸。

原视频不到 3 秒怎么办

可以转。时长由所选片段决定，最长 3 秒，App 不会把短视频补足到 3 秒。时间轴会限制最短可选长度；源片本身更短时，还受源片时长限制。选好后先预览再生成。

想要超过 3 秒的动态怎么办

  • 只保留最关键的瞬间：仍用“实况”模式，从长视频里截出最想留下的 3 秒。
  • 需要完整过程：直接把原视频发给对方，或作为视频发布。实况照片承担不了整段视频的时长。
  • 需要稍长一点的循环动图：可以改用视频转 GIF，片段最长 8 秒，说明见视频转 GIF 指南。GIF 不是实况照片，也不会出现在“照片”App 的“实况照片”分类里。

这篇教程不包含什么

《这图能改》不能生成超过 3 秒的实况照片，也不能把多张实况拼成一段更长的“实况视频”，也不会从其他平台下载视频。它只负责把相册里的本地视频生成实况照片并保存到“照片”图库。

常见问题

为什么视频转实况只能选 3 秒？

Apple 用“相机”拍摄实况照片时，会录下拍照前后各 1.5 秒，动态大约是 3 秒。《这图能改》转换时同样把片段限制在最长 3 秒，时间轴不会让你选出更长的范围。依据见 Apple《让照片生动起来》。

能不能把一整段很长的视频做成一张实况照片？

不能。一张实况照片只包含你选中的、最长 3 秒的片段。更长的内容请按视频分享或发布，或只截出最想保留的 3 秒再转换。

原视频不到 3 秒，还能转吗？

可以。时长由所选片段决定，不会补足到 3 秒。时间轴会限制最短可选长度，源片更短时还受源片时长限制。

怎么判断该选哪 3 秒？

先看完整视频，再在时间轴上标出动作最清楚、开头结尾比较完整的一段，并预览后再生成。封面要选片段里看起来清楚的一帧，因为别人先看到的是这张静帧。

封面必须选在片段正中间吗？

不必。可以在所选片段内任一时刻选一帧作为封面，预览和导出使用同一帧。用“相机”拍摄的实况照片也可以事后改封面，说明见 Apple《让照片生动起来》。

想要超过 3 秒的动态，该怎么做？

《这图能改》不能生成超过 3 秒的实况照片。需要完整过程，请直接发视频；需要稍长的动图，可以转成 GIF（最长 8 秒），见视频转 GIF 指南。GIF 不是实况照片。
