视频处理

iPhone 上怎么把视频转成 GIF 动图

作者与维护：HugeHard Studio · 更新于 2026年10月22日

想把视频里一个表情、一个动作做成 GIF 发群里或贴到网页上，不用找在线转换网站上传视频。在《这图能改》里导入视频，选好片段，调输出尺寸和帧率，生成后看一眼实际文件大小，再保存或分享。处理在手机本机完成。

操作步骤

  1. 在“工作台”选择“照片或视频”，导入要转的视频。
  2. 在编辑器里选择 GIF 模式，在时间轴上定好片段的起点和终点。GIF 一般越短越好，几秒钟的片段文件会小很多。
  3. 调整输出尺寸和帧率。尺寸越大、帧率越高，动图越顺，文件也越大；发聊天软件或论坛时，先用较小的尺寸试一次。
  4. 生成后在预览里看动图效果，并核对结果页显示的实际尺寸和文件大小。
  5. 满意就保存到照片图库，或用系统分享直接发出去。原视频不会被改动。

文件太大怎么办

GIF 不像视频那样能高效压缩，同样几秒钟，GIF 往往比原视频大。先缩短片段，再降低输出尺寸或帧率，通常比反复重试更快。生成好的 GIF 如果还要压到某个 KB 上限，可以再用图片压缩工具设目标大小，见图片压到指定大小。

常见问题

GIF 有没有声音？

没有。GIF 格式本身不带声音。想保留声音又要“会动的照片”，可以改做实况照片，见视频转实况照片。

转换时视频会上传吗？

不会。视频转 GIF 在手机本机处理，不会把视频上传到开发者服务器。

哪些视频能导入？

能通过 iOS 视频选择器读取的视频都可以尝试。MP4 只是容器，里面的编码也会影响兼容性，所以不保证每个视频都能转换。
