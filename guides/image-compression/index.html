图片处理

iPhone 照片怎么压到 200KB 或其他指定大小

作者与维护：HugeHard Studio · 更新于 2026年10月29日

在“工作台”导入照片，打开“调整”→“文件大小”，输入时选择 KB 单位并填 200，再切到“格式”选择 JPEG。生成后检查实际文件大小和像素尺寸；图片在本机处理，原图保留。

设置 200KB 或其他目标

  1. 在“工作台”选择照片并导入。图片编辑器底部选择“调整”，再点“文件大小”。
  2. 打开“限制文件大小”，点目标数值打开输入面板，单位选 KB，输入 200 并点“确认”。也可拖动刻度尺设置其他目标。目标必须在当前显示范围内，范围从最低值到源文件大小。
  3. 切到“格式”并选择 JPEG，再回到“调整”查看文件大小提示。JPEG 和 HEIC 会搜索编码质量，尝试在目标字节数内保留较高质量；是否达到目标以生成后的实际文件为准。透明图片转成 JPEG 时，透明区域会铺成白色。
  4. 点“生成”后检查预览、实际文件大小、输出格式和像素尺寸。结果页会显示大小与是否达到目标，再决定保存或分享。
  5. 如需保留其他格式，按相同方法设定目标并选对应输出格式；JPEG、HEIC、PNG 和 GIF 的编码方式不同，不能假设同一目标在所有格式下都能达到。

目标字节数、像素尺寸和裁剪范围是不同概念：裁剪改变保留的画面区域，像素尺寸改变输出宽高，文件大小则以字节计算。另见iPhone 照片裁剪、旋转和比例指南。

输入 GIF 并保持 GIF 输出时，所有帧、帧时长和循环次数都会保留；动画帧数与画面复杂度会影响体积，因此压到目标大小不作保证。

处理限制

PNG 无损输出、保留原尺寸，以及 GIF 的帧数和画面复杂度都会影响文件大小。图片处理最多读取 80 MP 源图，普通图片输出最长边上限为 8,192 px；超出范围时 App 会提示。不要仅凭目标输入值推断输出大小。

常见问题：像素合格但文件仍超限

像素尺寸和文件体积分别检查。照片即使符合对方要求的宽高像素，编码后的字节数仍可能高于限制。若结果仍大于目标，可在不违反像素要求的前提下，尝试调整格式；若允许缩小像素尺寸，可在“调整”→“像素尺寸”中改最长边（App 不会放大原图），再生成并查看实际文件。

为什么 PNG 可能大于 200KB？

PNG 使用无损编码，不会通过降低图像质量来缩小文件，所以可能无法达到 200KB 或其他目标。若素材和用途允许，可改选 JPEG；注意 JPEG 不保留透明区域，透明部分会铺成白色。若必须使用 PNG，请以实际输出为准。

“不超过 200KB”与“严格小于 200KB”有什么区别？

《这图能改》的 KB 按 1KB = 1,000 bytes 计算，因此 200KB 是 200,000 bytes。应用内目标判断采用“实际字节数 ≤ 目标”：正好 200,000 bytes 算达到“不超过 200KB”，但不满足严格的“小于 200KB”。若接收方要求严格小于，请把目标设在 200KB 以下留出余量，并核对导出文件的实际字节数；不要只看显示的四舍五入 KB 数值。

检查结果再交付

确认所需格式、像素尺寸和实际文件大小。即使未达到目标，也以生成文件本身和结果提示为准。压缩结果会写入新文件，原始素材保持不变。
