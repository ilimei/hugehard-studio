图片处理

图片怎么压到指定大小

作者与维护：HugeHard Studio · 更新于 2026年10月20日

目标大小是一个尝试值，不代表所有格式和素材都能达到。压缩后请以结果页显示的文件大小、格式与像素尺寸为准。

操作步骤

  1. 在“工作台”选择照片并导入；在图片编辑器底部选择“调整”，再选“文件大小”。图片处理在设备上完成，不覆盖原始文件。
  2. 打开“限制文件大小”，拖动刻度尺设置目标，也可点按数值精确输入。可选范围从当前最小值到源文件大小。文件大小与像素尺寸是两个独立选项；如需缩小画面，在“像素尺寸”中调整最长边，原图不会被放大。
  3. 在编辑器底部切到“格式”并选择输出格式，再回到“调整”查看对应提示。JPEG 和 HEIC 会搜索编码质量，尝试在目标字节数内保留较高质量；这不是达标保证。透明图片转成 JPEG 时，透明区域会铺成白色。
  4. 输入 GIF 并保持 GIF 输出时，所有帧、帧时长和循环次数都会保留。若启用文件大小限制后仍未达到目标，可在“调整”→“像素尺寸”中选择较小的最长边，再生成并检查实际文件。
  5. PNG 使用无损编码。它不会通过降低图像质量来缩小文件，所以结果可能仍大于目标。
  6. 查看预览中的实际文件大小和像素尺寸，再决定保存到照片或分享。即使未达到目标，结果页也会如实显示实际大小与提示。

处理限制

PNG 无损输出、保留原尺寸，以及 GIF 的帧数和画面复杂度都会影响文件大小。图片处理最多读取 80 MP 源图，普通图片输出最长边上限为 8,192 px；超出范围时 App 会提示。不要仅凭目标输入值推断输出大小。

检查结果再交付

确认所需格式、像素尺寸和实际字节大小。需要达到邮件或网站限制时，以结果文件本身为准；若 PNG 或保留原尺寸的 GIF 超过目标，可考虑允许缩小尺寸，或选用适合素材与用途的格式。压缩结果会写入新文件，原始素材保持不变。
