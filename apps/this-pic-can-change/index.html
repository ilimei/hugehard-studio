一张图的处理流程

HEIC · JPEG · PNG · GIF

在同一画布内裁剪、旋转或选比例；按需调整尺寸或压缩，生成后核对实际格式、像素尺寸和文件体积。

具体使用场景

把一张图片处理到符合用途要求。

图片用于上传或分享时，可能需要某种格式、受限的像素尺寸、特定构图或较小的文件体积。这个流程围绕同一张图片逐项调整，并核对实际输出。

01

格式、构图和输出都在同一处理流程中

选择 HEIC、JPEG、PNG 或 GIF 输出格式，在同一图片处理界面调整像素尺寸或压缩，并直接在画布上裁剪、旋转或选比例。生成后预览实际结果；保存或分享前可核对输出格式、像素尺寸和文件体积，原图保留。

截图交付、视频转实况、用户自备 API Key 的 AI、小组件和小游戏也在应用中提供，见下方功能列表。

为设备上的真实操作设计。支持细节与数据去向可在使用支持和隐私政策中查看。

01

六项图片与视频主工具

包含格式转换、裁剪与尺寸调整、图片压缩、视频转实况、视频压缩和视频转 GIF；导出结果会显示实际格式、尺寸或文件大小。查看 iPhone 视频转实况照片步骤。

02

截图交付助手

在“更多功能”→“截图交付”中，可按序拼接截图、选择画布、手动遮挡或确认本机 OCR 候选、添加用途水印并设置 KB 目标。导出后显示是否达标；预览不改动原图。

03

桌面照片与小游戏小组件

选择照片放上主屏幕，也可以设置照片拼图、点灯、迷宫和翻牌配对。照片与游戏进度保存在设备共享目录。

04

自备服务的 AI 创作

AI 生图和改图分别提供入口。你配置服务商、协议、模型、Base URL 和自己的 API Key；首次使用某组服务配置提交时，App 会显示接收方与发送内容并等待确认。更改地址、协议或模式后需再次确认。服务费用按所选服务方的规则收取，和 App 本机处理额度分开。
