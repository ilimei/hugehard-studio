# 这图能改

> “这图能改”是一款面向 iPhone 和 iPad、支持 iOS 17 及以上的图片与视频工具。英文站点使用名称 “This Pic Can Change”；App 界面为简体中文。TestFlight 1.0 (2) 公开外测正等待 Apple Beta 审核；公开页面暂不接受新测试员，审核通过后才会开放加入。

## 产品事实

- 当前 TestFlight 1.0 (2) 包含六项本机影像工具：视频转实况、视频压缩、视频转 GIF、图片压缩、格式转换和调整尺寸。
- 截图交付助手仍在开发中，未包含在当前 Beta。开发版计划支持按顺序拼接 1–10 张截图，选择画布尺寸、手动遮挡、确认本机 OCR 候选、添加用途水印并导出。
- 桌面功能包括照片小组件和四款小游戏。照片与游戏进度存储在设备共享目录。
- 可选 AI 生图与改图由用户配置服务、协议、模型、Base URL 和 API Key。AI 请求从设备直接发往所选服务商；服务商可能按其政策处理内容并收费。
- [查看 TestFlight（审核中）](https://testflight.apple.com/join/GK8ht2vv)。当前链接页尚不接受新测试员，需等 Apple Beta 审核通过后开放。
