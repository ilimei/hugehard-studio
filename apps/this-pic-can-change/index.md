# 这图能改

> “这图能改”是一款为 iPhone 设计、支持 iOS 17 及以上的图片与视频工具。英文站点使用名称 “This Pic Can Change”；App 界面为简体中文。iPad 可使用兼容模式，不提供专用 iPad 版式。v1.2 (5) 已上传 App Store Connect 内部测试，状态 Ready to Test，准备 App Review；尚未在 App Store 上架。

## 产品事实

- v1.2 (5) 提供六项本机影像主工具：视频转实况、视频压缩、视频转 GIF、图片压缩、格式转换和调整尺寸；当前构建也包含截图交付助手。
- 主导航顺序为“工作台、更多功能、最近、设置”。桌面功能包括照片小组件和四款小游戏；照片与游戏进度存储在设备共享目录。
- 本机处理每周有 20 次免费成功使用；一次性非消耗型永久解锁可无限使用全部本机工具。
- 可选 AI 生图与改图由用户配置服务、协议、模型、Base URL 和 API Key。请求从设备直接发往所选服务商；首次提交前会显示接收方和发送内容供用户确认。服务商可能按其政策处理内容并单独收费。
- [旧版公开 TestFlight 页面（可能仍指向 1.0 (2)，不代表当前构建）](https://testflight.apple.com/join/GK8ht2vv)。该旧链接不是 v1.2 (5) 的公开下载入口。
