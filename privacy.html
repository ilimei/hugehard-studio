网站访问与数据处理

网站只在你明确选择“同意统计”后加载 Google Analytics；未选择或拒绝时，不加载 Google tag，也不向 Google 发送统计请求。启用后会记录页面访问，并在点击 TestFlight 公测链接时发送 testflight_click 事件；事件只含固定入口位置、页面路径和页面语言。页面地址和站内来源只保留路径，外部来源只保留域名；查询参数和片段不会发送。Google Analytics 可能处理浏览器、设备和访问请求信息，并在 hugehard.app 主机设置会话级第一方统计 Cookie。网站不启用广告、Google Signals 或广告个性化，不发送账号用户 ID、邮件内容、任意链接文字、照片、视频、提示词或 App 使用记录。选择保存在本机浏览器，可通过页脚“统计设置”撤回或更改；撤回后会停止统计并清除可识别的 Google Analytics Cookie。请参阅 Google 隐私政策。

域名解析与网站代理由 Cloudflare 提供，网站内容由 GitHub Pages 托管。托管与代理服务可能处理访问 IP 与请求信息，具体见 GitHub Pages 数据收集说明、GitHub 一般隐私声明和 Cloudflare 隐私政策。主页和徽章页显示由第三方站点托管的徽章图片；查看这些页面时，图片服务会收到相应的访问请求信息，服务列表见徽章页。网站没有联系表单或广告。

如果你主动点击客服邮箱链接并发送邮件，邮件内容会由客服邮箱接收和处理。点击链接本身不会自动发送邮件。

GitHub Pages 托管日志

GitHub 官方说明，访问 GitHub Pages 网站时会记录并为安全目的保存访客 IP 地址，无论访客是否登录。GitHub 的一般隐私声明也说明其可能记录来源网站、访问时间、浏览页面和点击链接等网站使用数据。域名解析与网站代理由 Cloudflare 提供，访问请求可能经过 Cloudflare 并由其按隐私政策处理访问 IP 与请求信息。请阅读 GitHub Pages 数据收集说明、GitHub 一般隐私声明和 Cloudflare 隐私政策了解托管与代理服务的数据处理方式。

上述访问日志与请求信息由 GitHub Pages 托管层或 Cloudflare 代理层按各自隐私政策处理，属于网站服务层，不是 App 遥测。产品自身的数据处理说明请阅读《这图能改》隐私政策。
