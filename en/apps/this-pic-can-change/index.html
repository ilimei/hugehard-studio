A concrete use case

Turn a photo or video clip into the version you need.

A photo for upload or sharing may come with requirements for format, aspect ratio, pixel dimensions, or file size. To express or keep a particular moment from a video, select a clip for a GIF or Live Photo; video compression is also available. In both workflows, set the desired output, inspect the actual result, then decide whether to save or share. The source remains unchanged.

01

Image: adjust it for upload or sharing

Choose HEIC, JPEG, PNG, or GIF as the output format; adjust pixel dimensions or compression in the same image workflow; then crop, rotate, or set an aspect ratio directly on the canvas. Generate, then preview the actual result. Before saving or sharing, check the actual output format, pixel dimensions, and file size; the original is preserved.

02

Video: keep the segment you want

Choose a video segment for a GIF and adjust its output dimensions and frame rate. For a Live Photo, select the exact cover frame and inspect it in preview, then set crop, quality, and sound. Video compression is also available. Export does not change the source video.

Screenshot Delivery, AI with your own API key, widgets, and games are additional tools; see the feature list below.

01

On-device photo and video tools

Make a Live Photo from video, compress video, create a GIF from video, compress images, convert formats, and resize images. The six core media tools process files on device. See how to turn an iPhone video into a Live Photo.

02

Screenshot Delivery

In More Features → Screenshot Delivery, add screenshots in order, choose a canvas, redact manually or confirm on-device OCR suggestions, add a purpose watermark, and set a target in KB. The export reports whether the target was reached; preview does not alter the originals.

03

Photo and game widgets

Choose photos for the home screen or add a photo puzzle, lights game, maze, or matching game. Photos and game progress stay in the device’s shared app storage.

04

AI with a service you configure

Image generation and image editing have separate entry points. You configure the provider, protocol, model, Base URL, and your own API key. On a first submission for a service configuration, the app shows the receiving host and content for confirmation; changing the address, protocol, or mode requires confirmation again. The provider’s charges are separate from the app’s local-processing allowance.
