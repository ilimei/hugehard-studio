Image processing

How to compress an image to a target size

Written and maintained by HugeHard Studio · Updated 20 October 2026

A target is a value to try, not a guarantee for every format or source image. After compression, use the result screen’s actual file size, format, and pixel dimensions as your reference. The app interface is Simplified Chinese; labels below include their on-screen wording.

Steps

  1. In Workbench (“工作台”), select and import a photo. In the image editor, choose Adjust (“调整”), then File Size (“文件大小”). Processing happens on device and does not overwrite the original.
  2. Turn on Limit File Size (“限制文件大小”), then drag the ruler or tap its value to enter a precise target. The available range runs from the minimum for the current source to the source file’s size. File Size and Pixel Size are separate controls. To reduce dimensions, choose a maximum edge in Pixel Size (“像素尺寸”); the app does not enlarge the source.
  3. Choose Format (“格式”) in the editor’s bottom bar and select an output format, then return to Adjust (“调整”) to read its note. JPEG and HEIC search encoding quality to try to keep better quality within the target byte count. This does not guarantee the target will be met. When a transparent image is converted to JPEG, transparent areas are filled with white.
  4. When the input is an animated GIF and GIF remains the output format, all frames, frame delays, and the loop count are preserved. If the file-size limit is still not reached, choose a smaller maximum edge under Adjust (“调整”) → Pixel Size (“像素尺寸”), then generate and check the actual file.
  5. PNG uses lossless encoding. It does not reduce image quality to make the file smaller, so the output may remain above the target.
  6. Check the result preview for actual file size and pixel dimensions, then save to Photos or share. If the target is missed, the result screen shows the actual size and an explanation.

Limits to keep in mind

Lossless PNG output, keeping original dimensions, and the number and complexity of GIF frames affect file size. Image processing accepts source images up to 80 megapixels, with an output long-edge limit of 8,192 pixels; the app reports files outside its supported range. Do not infer the output size from the target field alone.

Check the file before sharing

Confirm the required format, pixel dimensions, and actual byte size. If an email or website has a file limit, check the exported file itself. If PNG or a full-size GIF is over the target, consider allowing a smaller output dimension or choosing a format that suits the material and use. Compression writes a new file and leaves the source unchanged.
