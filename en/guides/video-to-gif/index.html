How to turn an iPhone video into a GIF

Written and maintained by HugeHard Studio · Updated 28 October 2026

To make a reaction GIF or short loop from an iPhone video, open Workbench (“工作台”), choose Photo or Video (“照片或视频”) and import the clip. Select GIF in the editor’s bottom mode bar, set the segment, output size, and frame rate, then generate and check the actual dimensions and file size before saving or sharing. Processing runs on the phone.

Steps

  1. In Workbench (“工作台”), choose Photo or Video (“照片或视频”) and import the video. In the editor’s bottom mode bar, select GIF.
  2. Set the clip’s start and end on the timeline. It can be up to 8 seconds, or the source duration if shorter; a 0.5-second minimum applies when the source is long enough.
  3. Set output size and frame rate. Larger size and higher frame rate look smoother but make bigger files; for chat apps or forums, try a smaller size first.
  4. Generate, play the preview, and check the actual dimensions and file size on the result screen.
  5. Save to the photo library or share it. The original video is not changed.

If the GIF is too large

GIF compresses far less efficiently than video, so a few seconds can be larger than the source clip. This tool supports 1–12 fps and output up to a 1,280-pixel long edge; it keeps the aspect ratio and does not enlarge the source. Shorten the clip first, then lower output size or frame rate. The optional size target is an attempt, not a guarantee; check the result screen for the actual file size. For a KB target, see compress an image to a target size.

FAQ

Does a GIF keep sound?

No. The GIF format has no audio. If you want a moving photo with sound, make a Live Photo instead; see video to Live Photo.

Is the video uploaded?

No. Video to GIF runs on the device and does not upload the video to the developer's servers.

Which videos can I import?

Anything iOS's video picker can read is worth trying. MP4 is only a container and the codec inside also matters, so not every video is guaranteed to convert.

How long and what size can a GIF clip be?

A clip can be up to 8 seconds, or the source duration if shorter; a 0.5-second minimum applies when the source is long enough. The frame rate is 1–12 fps and the output long edge is limited to 1,280 pixels without upscaling. The optional size target is an attempt, not a guarantee.
