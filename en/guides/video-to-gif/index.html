How to turn a video into a GIF on iPhone

Written and maintained by HugeHard Studio · Updated 22 October 2026

To make a reaction GIF or a short loop from a video, you don't need to upload the video to a converter website. Import it into This Pic Can Change, pick the clip, set output size and frame rate, then check the real file size before saving or sharing. Processing happens on the phone.

Steps

  1. On the Workspace tab, choose Photos or Videos and import the video.
  2. Choose GIF mode in the editor and set the start and end of the clip on the timeline. Shorter clips give much smaller GIFs.
  3. Set output size and frame rate. Larger size and higher frame rate look smoother but make bigger files; for chat apps or forums, try a smaller size first.
  4. Generate, play the preview, and check the actual dimensions and file size on the result screen.
  5. Save to the photo library or share it. The original video is not changed.

If the GIF is too large

GIF compresses far worse than video, so a few seconds of GIF is often bigger than the source clip. Shorten the clip first, then lower output size or frame rate. If the GIF still has to fit a KB limit, use the image compression tool with a target size; see compress an image to a target size.

FAQ

Does a GIF keep sound?

No. The GIF format has no audio. If you want a moving photo with sound, make a Live Photo instead; see video to Live Photo.

Is the video uploaded?

No. Video to GIF runs on the device and does not upload the video to the developer's servers.

Which videos can I import?

Anything iOS's video picker can read is worth trying. MP4 is only a container and the codec inside also matters, so not every video is guaranteed to convert.
