Screenshot organization

How to join, redact, and deliver screenshots

Written and maintained by HugeHard Studio · Updated 14 October 2026

Screenshot Delivery combines multiple screenshots into a new image on device. Before exporting, check their order, canvas size, redaction coverage, and final file. OCR offers candidates only; it does not replace a manual review.

Current beta scope

This guide describes screenshot delivery in development. It is not included in TestFlight 1.0 (2); the current beta has six on-device media tools.

Join and arrange the screenshots

  1. Open Tools (“工具”) → Screenshot Delivery (“截图交付助手”) and select 1–10 screenshots in order. You can move a screenshot up or remove it. Confirm that the thumbnail order matches the order you want in the final image.
  2. Choose vertical or horizontal joining. Set a common width for vertical joining or common height for horizontal joining. Choose 720 px, 1,080 px, or source dimensions. The tool does not enlarge images to match the selected size.
  3. Choose Direct Join (“直接拼接”) to connect the images, or Numbered Captions (“编号说明”) to add an automatic number and optional title and description before each screenshot. Adjust the canvas background and image spacing if needed.

Redact and review privacy

  1. On the full-length image editor, drag to add black rectangles over sensitive areas. You can undo or clear them. You can also run on-device OCR to find candidate phone numbers, email addresses, and national ID numbers.
  2. OCR candidates start unchecked and are applied only after you confirm them. Recognition may miss text. Zoom in and review the entire joined image, including its edges and areas around captions. In the numbered-caption layout, OCR checks screenshot pixels rather than the title or description text.
  3. Add a purpose watermark if needed. It is tiled across the image; the preview and exported file use the same coordinates and layout.
  4. Changing the layout, caption text, direction, dimensions, or spacing clears existing redactions. If you had already redacted the image, the app still requires a “Review redactions” (“检查打码”) confirmation on the new canvas before export. Check that each rectangle covers the intended sensitive information.

Set export options and check the file

  1. Choose JPEG or PNG and enter a target from 1 to 50,000 KB. JPEG searches encoding quality and reports whether the final byte count meets the target; it is not a guarantee. PNG uses lossless encoding and may remain above the target.
  2. Review the final preview, pixel dimensions, and actual file size. If the joined image would exceed a 16,000-pixel long edge or 32 megapixels, the app asks you to lower the dimensions or use fewer screenshots.
  3. The new file flattens the black rectangles into its pixels. The original screenshot files are not modified or deleted, and the output does not retain the original image EXIF. After checking the result, save it to Photos or share it.

Export note

JPEG may miss a target depending on image complexity; PNG prioritizes lossless image quality. Use the byte size and dimensions shown by the app as the actual result. Joining, OCR, and redaction happen on device.
