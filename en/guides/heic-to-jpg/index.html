How to convert an iPhone HEIC photo to JPG

Written and maintained by HugeHard Studio · Updated 22 October 2026

iPhone saves photos as HEIC by default. The files are small, but plenty of upload forms and older computers can't read them. Import the photo into This Pic Can Change, pick JPEG as the output format, check the format and file size, then save. Conversion runs on the phone and the original is kept.

Steps

  1. On the Workspace tab, import the photo. HEIC works, and so do PNG, GIF, and other readable formats.
  2. Switch to Format at the bottom of the image editor and choose JPEG.
  3. If the site has size or dimension rules, switch to Adjust and change the long edge under Pixel Size, or set a target under File Size.
  4. Generate, then check output format, pixel dimensions, and file size on the result screen.
  5. Save to the photo library or share. The original HEIC is not overwritten.

Before converting to JPG

JPEG has no transparency, so transparent areas become white. Converting HEIC to JPEG re-encodes the image and the file usually gets somewhat larger. The current version does not guarantee HDR highlights and color are preserved.

FAQ

Does HEIC to JPG lose quality?

It re-encodes once, which is hard to notice at normal quality. If you also set a small target file size, the app lowers encoding quality to fit, and the loss becomes more visible. Judge by the preview.

Can I convert to PNG instead?

Yes. Output formats are HEIC, JPEG, PNG, and GIF. PNG is lossless and usually much larger than JPEG, so JPEG is the usual choice when size matters.

Are photos uploaded?

No. Format conversion runs on the device and nothing is uploaded to the developer's servers.
