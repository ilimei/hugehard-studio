How to convert an iPhone HEIC photo to JPG

Written and maintained by HugeHard Studio · Updated 13 November 2026 · Samples exported with the app’s image-processing code on macOS on 13 November; not an iPhone device test, values apply to the listed inputs

If a receiver requires JPG/JPEG, import the HEIC photo into This Pic Can Change, choose JPEG under Format (“格式”), then generate and inspect the result. Conversion runs on device and preserves the original; file size may change with the image and encoding settings.

Steps

  1. On the Workspace tab, import the photo. HEIC works, and so do PNG, GIF, and other readable formats.
  2. Switch to Format at the bottom of the image editor and choose JPEG.
  3. If the receiver has pixel or file-size limits, switch to Adjust (“调整”) and change the long edge under Pixel Size (“像素尺寸”), or set a target under File Size (“文件大小”). HEIC-to-JPEG conversion re-encodes the image, so the file may grow or shrink. If it misses the size target, read the result notice and adjust the long edge as needed. See the image compression guide.
  4. Generate, then check output format, pixel dimensions, and file size on the result screen.
  5. Save to the photo library or share. The original HEIC is not overwritten.

Choose a format for the receiver

  • If HEIC is accepted: you can keep the original and avoid an unnecessary conversion. Apple describes HEIF as more storage-efficient than JPEG in supported workflows; that does not predict the size of a particular image conversion. Read Apple’s HEIF/HEVC guide.
  • If JPG/JPEG is required: choose JPEG. Conversion re-encodes the image, and the resulting file size depends on the content, pixel dimensions, and encoding settings.
  • If transparency is needed: choose PNG if the receiver accepts it. JPEG has no transparency, so transparent areas are filled with white.

HDR photos

If the source is HDR, compare highlights and color with the original after generating. This Pic Can Change does not guarantee that HDR highlights and color are preserved.

FAQ

Why can an HEIC-to-JPG file be larger?

HEIC to JPEG re-encodes the image. The output size depends on image content, pixel dimensions, and encoding settings, so it may be larger or smaller. HEIF is generally more storage-efficient than JPEG, but that does not predict the size of a particular conversion. Check the generated result; if it is still over a limit, set a target under Adjust (“调整”) → File Size (“文件大小”) and generate again.

Why does a transparent PNG turn white when converted to JPG?

JPEG does not support transparency. When This Pic Can Change converts a PNG to JPEG, it fills transparent areas with white. If you need transparency and the receiver accepts PNG, choose PNG output.

Can HEIC-to-JPG conversion change the image?

HEIC to JPEG re-encodes the image, so the result can differ from the source. With a file-size limit enabled, the app searches encoding quality to try to meet the target. The result depends on the source and settings, so check the preview after generating.

Can I convert to PNG?

Yes. Output formats include HEIC, JPEG, PNG, and GIF. PNG uses lossless encoding and can preserve transparency in the source, but file size still depends on image content and pixel dimensions. Check that the receiver accepts the format you choose.

Are photos uploaded?

No. Format conversion runs on the device and nothing is uploaded to the developer's servers.
