Website privacy · 27 October 2026

Website visits and data handling

The site loads Google Analytics only after you explicitly choose “Allow analytics.” With no choice or a rejection, it does not load the Google tag or send analytics requests to Google. When enabled, it records page views and a testflight_click event when you choose a TestFlight beta link; the event contains only a fixed placement value, page path, and page language. Page addresses and internal referrers are limited to paths; external referrers are limited to their origin. Query strings and fragments are not sent. Google Analytics may process browser, device, and visit-request information and set a session-only first-party analytics cookie on the hugehard.app host. Advertising, Google Signals, and ad personalization are disabled. We do not send an account user ID, email contents, arbitrary link text, photos, videos, prompts, or app-usage records. Your choice is stored in this browser and can be changed or withdrawn through “Analytics settings” in the footer; withdrawal stops analytics and clears identifiable Google Analytics cookies. See Google’s Privacy Policy.

Cloudflare provides DNS resolution and website proxying; GitHub Pages hosts the site content. These services may process visitor IP addresses and request information. See the GitHub Pages data collection notice, GitHub General Privacy Statement, and Cloudflare Privacy Policy for details. The studio home page and badges page load badge images hosted by third-party listing sites; those image services receive the related access request information. See the badges page for the list. The site has no contact form or advertising.

If you choose to open the support email link and send a message, its contents will be received and handled by the support mailbox. Clicking the link alone does not send an email.

Hosting and proxy logs

GitHub states that it records and retains visitor IP addresses for security when people visit GitHub Pages sites, whether or not they are signed in. Its general privacy statement also says it may record the referring site, visit time, pages viewed, and links clicked. Cloudflare provides DNS resolution and website proxying; requests may pass through Cloudflare, which may process visitor IP addresses and request information under its privacy policy. Consult the GitHub Pages notice, GitHub General Privacy Statement, and Cloudflare Privacy Policy linked above for each provider’s handling.

Hosting logs and proxy request information are handled by GitHub Pages and Cloudflare under their respective policies. They are website-service data, not app telemetry. For the product’s data practices, read the This Pic Can Change app privacy policy.
