Website privacy · 14 October 2026

Website visits and data handling

Cloudflare provides DNS resolution and website proxying; GitHub Pages hosts the site content. These services may process visitor IP addresses and request information. See the GitHub Pages data collection notice, GitHub General Privacy Statement, and Cloudflare Privacy Policy for details. The site has no contact form, advertising, third-party analytics, or tracking scripts, and embeds no external content.

If you choose to open the support email link and send a message, its contents will be received and handled by the support mailbox. Clicking the link alone does not send an email.

Hosting and proxy logs

GitHub states that it records and retains visitor IP addresses for security when people visit GitHub Pages sites, whether or not they are signed in. Its general privacy statement also says it may record the referring site, visit time, pages viewed, and links clicked. Cloudflare provides DNS resolution and website proxying; requests may pass through Cloudflare, which may process visitor IP addresses and request information under its privacy policy. Consult the GitHub Pages notice, GitHub General Privacy Statement, and Cloudflare Privacy Policy linked above for each provider’s handling.

Hosting logs and proxy request information are handled by GitHub Pages and Cloudflare under their respective policies. They are website-service data, not app telemetry. For the product’s data practices, read the This Pic Can Change app privacy policy.
